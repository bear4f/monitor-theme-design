# monitor-theme-design

[monitor](https://github.com/monitor-probe/monitor) 的公开页主题。

Fork 自 [tom2almighty/monitor-theme-design](https://github.com/tom2almighty/monitor-theme-design)，在原主题上增加**访客权限**，其余界面保持不变。原主题 Fork 自 [stqfdyr/monitor-theme-serverstatus](https://github.com/monitor-probe/monitor-theme-serverstatus)，结合 tweakcn(ShadcnUI) Tokens 与 Zen Browser 风格的噪点磨砂效果。

![预览](preview.png)

## 特性

- **账单**：导航里多一页「账单」，汇总月均成本和未来的续费，带一个可翻月的续费日历和每个节点的费用明细；可以选择是否给访客看。见下文[账单](#账单)。
- **自定义页脚**：页脚文字、跳转链接和备注都可以在主题设置里改，也可以关掉 Powered by 与主题署名。见下文[自定义页脚](#自定义页脚)。
- **实时图表**：监控页的时间范围多一档「实时」，CPU、内存、网络、硬盘按每次上报画点，保留最近 10 分钟。见下文[实时图表](#实时图表)。
- **延迟摘要**：首页每个节点下方直接显示最多三条线路的最新延迟、最近一小时走势与丢包率，不用展开。见下文[延迟摘要](#延迟摘要)。
- **访客权限**：未登录的访客默认只能看网络延迟；系统概览、资源历史图表和到期时间登录后台后才显示。见下文[访客权限](#访客权限)。
- **配色切换**：均含亮色/暗色模式。延迟图给每条线路一个颜色，每套配色各有一组 8 个、深浅模式分别取值，按顺序分配，8 条线路以内不重复。
- **噪点与磨砂效果**：两个参数各支持 0%~100% 无级调节。

## 延迟摘要

首页列表里每个节点下方有一条摘要：最多三条线路并排，每条是线路名、最新一次延迟、最近一小时的走势线和丢包率。丢包达到 1% 标为琥珀色，达到 5% 标为红色。鼠标移到走势线上，会标出指针所在那一点的时间和延迟（那一分钟全部超时则显示「超时」）。展开节点时摘要收起，由完整的延迟图代替；窄屏上只留线路名和延迟数值。

后台「主题」页本主题的设置里，「首页列表」一组有两项：

| 设置 | 默认 | 说明 |
|---|---|---|
| 节点下方显示延迟摘要 | 开 | 关闭后列表和原来一样，也不再发下面说的查询 |
| 摘要显示的延迟线路 | 空 | 每行一个延迟监控的名称，按填写顺序优先，每个节点显示它有的前三条；留空自动取前三条 |

线路可以多填：比如依次填三条国内线路和三条海外线路，有国内监控的节点显示国内三条，没有的自动显示后面的。

开启后每个节点每分钟多一次延迟查询（最近一小时、60 个点），同时最多十个，页面在后台时不查。

摘要是整批一起显示的，不会一行一行冒出来：

- 再次访问时，上次的摘要存在浏览器本地（24 小时内有效），和列表在同一帧画出来，新数据到了再整批替换；查询在节点列表返回之前就已经发出。
- 第一次访问没有本地数据：页面一打开、主脚本还在下载时，`index.html` 里的一小段脚本就先去取站点信息、节点列表、主题设置和前 24 个节点的延迟，脚本下载完时这些大多已经到了，摘要基本随列表一起出现。没赶上的先显示占位条，全部查完（或 2.5 秒到点）后一次显示。
- 每分钟的刷新同样整批替换。延迟对访客本来就可见，所以这一条不受访客权限影响。

## 实时图表

监控页右上角的时间范围最左边是「实时」。历史数据最短是 1 小时、按分钟左右聚合，短暂的峰值会被抹平；「实时」画的是每一次上报，适合跑测速、看突发流量时盯着看。

- 数据来自首页列表本来就在用的推送，不向 hub 多发请求。点的间隔是探针的上报间隔（通常几秒），不是推送间隔。
- 页面一打开就在后台为所有节点记录，切到「实时」或换节点时，这段时间的数据已经在图上；保留最近 10 分钟，刷新页面后重新开始。
- 上报中断超过 20 秒，线会断开，不会连过去。
- 延迟不在推送里，「延迟」标签没有这一档，按 1 小时显示。
- 谁能看资源历史图表谁就能用，默认只有管理员。

## 账单

导航里的「账单」页（地址 `/bill`）由三块组成，全部从节点已有的价格、币种、付费周期和到期日算出，不向 hub 多发请求：

- **费用指标**：月均成本（附折合每年）、未来 30 天续费、未来 12 个月续费、最高花费节点。
- **续费日历**：按月翻页，有节点到期的日子标出台数；旁边列出当月到期的节点、续费价格和合计，点某一天只看那一天。
- **节点费用明细**：每个节点的状态、当期费用、月均成本、到期时间和剩余天数，可按月均成本或到期时间排序。

几点口径：

- 合计一律折成人民币，汇率按下面的顺序取，页面上会写明每个币种用的是哪一种：
  1. 主题设置「账单」→「手动汇率」里填了的币种，用填的值，例如 `USD = 7.1`。
  2. 其余币种用当天汇率：打开账单页时由浏览器向公开接口去取，依次尝试 [ExchangeRate-API](https://www.exchangerate-api.com)、[currency-api](https://github.com/fawazahmed0/exchange-api)（jsDelivr）、[Frankfurter](https://frankfurter.dev)（欧洲央行），前一个取不到才试下一个。结果在浏览器里缓存 12 小时。
  3. 三个都取不到，或者在设置里关掉了「使用当天汇率」，用内置的参考汇率。
- 当天汇率只在打开账单页时才请求，其他页面不会向任何第三方发请求；关掉「使用当天汇率」后账单页也不会。请求是从查看者的浏览器直接发给这些接口的，对方能看到查看者的 IP。
- 没有汇率的币种不计入合计，页面上会注明。
- 没填价格（价格为 0）的节点显示「免费」，不计入任何合计；一次性买断的节点不计入月均成本。
- hub 只知道每个节点的下一个到期日。日历里再往后的各期是按当前价格和周期推算的，标有「推算」；「未来 12 个月续费」同样按每一次续费累计，月付的节点算 12 次。
- 「今天」取 hub 的日期（由节点的到期日和剩余天数反推），不用访客浏览器的时钟。

默认只有登录后台才能看到；「访客权限」里的「访客可查看账单」打开后访客也能看。

### 标记已续费

登录后台后，续费日历右侧的列表里，每个当期到期的节点后面有一个「已续费」按钮。点它、再点「确认」，节点的到期日就顺延一个付费周期（年付的到明年同一天，月付的到下个月同一天），列表上方会出现一条带「撤销」的提示。

- 这个按钮改的是 hub 里这个节点的到期日，和在后台节点设置里手动改是同一件事，用的也是后台保存节点的那个接口（`PUT /api/nodes/{id}`，只发到期日这一项，其余设置不动）。首页的到期列、hub 的到期提醒都会跟着变。
- 只有登录的站长能看到按钮；开放给访客看账单时，访客看不到。
- 标着「推算」的行（还没到的后续各期）和一次性买断的节点没有这个按钮。
- hub 自己也会顺延：节点过了到期日仍然在线，hub 会在当天把到期日往后推一个周期。这个按钮用于提前续费后想让账单马上对上的情况。
- 这个接口不在 hub 给主题列出的接口之内，是借用了后台的。hub 以后要是改了它，按钮会报错而不会改坏数据，届时需要更新主题。

## 自定义页脚

后台「主题」页本主题的设置里，「页脚」一组有四项：

| 设置 | 默认 | 说明 |
|---|---|---|
| 页脚文字 | 空 | 显示在页脚左侧，纯文本；留空显示站点名称 |
| 页脚链接与备注 | 空 | 每行一项，最多 8 项 |
| 页脚位置 | 两端 | 两端（文字在左、链接在右）、居中（链接在上、文字在下）、靠左、靠右 |
| 显示 Powered by 与主题署名 | 开 | 关闭后页脚只剩上面两项自定义内容 |

「页脚链接与备注」的写法：

```
TG | https://t.me/yourname
NS | https://www.nodeseek.com/space/12345
邮箱 | mailto:you@example.com
仅供测试，不保证可用性
```

- `名称 | 链接` 显示为可点击的链接，竖线半角全角都行；Telegram 和邮箱链接有各自的小图标，其余是外链图标。
- 只写名称、不写链接的一行显示为纯文字备注。
- 链接只支持 `http`、`https` 和 `mailto`，其他写法（比如 `tg://`）不会变成链接，按纯文字显示。
- 四项都不改时，页脚和原来一样。

## 访客权限

在后台「主题」页点本主题卡片上的设置按钮，「访客权限」一组有五项开关，只对未登录的访客生效，管理员登录后始终能看到全部内容：

| 设置 | 默认 | 关闭后访客看不到 |
|---|---|---|
| 访客可查看「系统概览」 | 关 | 展开节点后的「系统概览」标签（系统信息、资源监控、流量统计、账期信息），以及监控页标题里的在线时长和 agent 版本 |
| 访客可查看资源历史图表 | 关 | 监控页的 CPU / 内存 / 网络 / 硬盘图表，只留延迟图 |
| 访客可查看列表实时指标 | 开 | 首页列表的系统、在线、到期、负载、网速、CPU、内存、硬盘、流量各列和顶部的网速、流量汇总，只留状态、名称、位置 |
| 访客可查看到期时间 | 关 | 首页列表的「到期」列，以及系统概览「账期信息」里的到期日与剩余天数 |
| 访客可查看账单 | 关 | 导航里的「账单」标签和整个账单页；直接访问 `/bill` 显示首页列表 |

设置还没读到时（包括 hub 1.2.0 及更早没有主题设置接口的情况）按默认值处理，不会先把内容画出来再收回。

> [!WARNING]
> 这是**显示层**的限制，不是接口层的权限。主题只是不画这些内容，hub 的 `/api/nodes` 和 `/api/ws` 对匿名请求照样返回 CPU、内存、流量、价格、到期日等字段，懂技术的访客打开浏览器开发者工具就能看到。要让数据真正不出站，只能由 hub 不输出：把节点设为不公开，或关闭「开放公开状态页」。

## 安装

### 方法一：后台上传压缩包

1. 在 [Releases](https://github.com/bear4f/monitor-theme-design/releases) 页面下载最新的 `theme.tar.gz`。
2. 登录 monitor hub 后台，进入「主题」管理页面。
3. 上传 `theme.tar.gz` 完成安装。卡片上的 ⟳ 按钮可检查本仓库是否有新版本。

### 方法二：解压至目录

将 release 产物解压到 hub 所在主机 `--themes` 目录下的 `monitor-theme-design/` 文件夹：

```bash
mkdir -p /path/to/monitor/themes/monitor-theme-design
tar -xzf theme.tar.gz -C /path/to/monitor/themes/monitor-theme-design
```

然后在后台「主题」页刷新并选中切换。

## 路由

主题用到两个前端路由：`/node/{id}`（监控页）和 `/bill`（账单页）。hub 前面有按路径放行的反向代理或 WAF 时，要把这两个前缀加进去，否则会出现「点进去正常，一刷新就被拦」。
